    The Atelier

    WPA treats conversion like developing film: frames go onto the bed, the safelight sweeps, and a developed file with a stamped size delta comes back. Hover any developed frame to wipe between original and result.

    Saving

    Downloads try the native Save-As dialog first, then fall back to your browser's download manager. If a preview frame blocks automatic saving, use the ↗ button on any frame, run SAVE EACH, or hover a developed frame and right-click the image → “Save image as”.

    Privacy

    Decoding and encoding run entirely in your browser through the Canvas API. Nothing is uploaded, stored or logged — close the tab and the darkroom is gone. It even works offline.
